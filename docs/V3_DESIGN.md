# 3.0 设计：三种时钟，三类组件

## 时间与控制边界

声学帧以 100 ms 更新；模型以流式块输出；会话与响应按事件维护归属。
三者不能用同一个“结束”标志替代。模型 LISTEN、响应自然结束、用户取消和播放器停止分别记账。
每个响应 ID 贯穿后端、传输和客户端，只有属于当前响应的事件能够更新播放状态。

## 主链路

MiniCPM-o 与当前独占 LoRA 处理端到端回答。声学 MLP 使用因果帧特征判断语轮，
滚动 ASR 为 TrustGate 提供风险语义与置信度。限定续讲保留被打断的低风险响应上下文，
不把语音取消当成任意敏感操作的授权。客户端停止本地播放，后端处理响应归属与迟到输出。

## 观察路径

动作头读取真实因果 hidden；EasyTurn 与 Smart Turn 读取有界音频前缀。
观察结果包含输入范围、模型 / 权重哈希、推理耗时和年龄。异步队列最多保留一个待处理请求，
会话终止会丢弃旧结果。观察结果与控制决策分离，当前组件模式不由旁路自动控制主回答。

## 训练接口

动作模型包含残差和直接两种形式；因果策略包含声学、语义、Transformer 融合与多任务输出。
它们以显式 feature 维度、因果掩码、状态和 checkpoint 契约连接训练 / 推理。
Demo 的已加载动作头与语义侧车分别标识，不将研究接口误当成在线统一策略。

## 适配器隔离

候选适配器独占模型会话，不与发布 GRPO adapter 叠加。进入和退出时清理 KV / 音频 / TTS 状态，
逐个验证 LoRA 文件与模型张量，结束后恢复默认。初始化不完整或恢复失败时不继续租借会话。

## 来源与撤销

可撤销记忆读取来源、写入和撤销事件，训练独立的状态更新与查询行为。
协议面板使用固定表达的事件特征缓存、训练集归一化和全部 18 份 checkpoint；
它不接麦克风、不清除主模型 KV。与主语音路径整合需要明确的来源输入与运行时契约。

## 可复现部署

上游 Demo 固定到一个 commit，增量补丁与 owned overlay 均哈希校验。
运行配置和模型路径放在外部环境文件。日志、音频与 checkpoint 放在运行目录，
源码发布只包含设计、实现、测试与接线材料。
